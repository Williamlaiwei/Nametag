# 使用者情境(2026-10-20)

原本的定位是「聚會上快速記住誰是誰」。這份文件把用途擴大成「認識的人的日記」:記人、記每次見面、記人和人的關係。

## 五個情境

| # | 角色 | 一句話 | 他最需要 |
|---|---|---|---|
| 1 | 小美(交友軟體常用者) | 約會的人很多,像記帳一樣記 | 對這個人的了解、好感度、個人資訊,之後能**篩選**出最喜歡的 |
| 2 | 小明(很會交朋友) | 當下加了聯絡方式,回去沒聊,就忘了怎麼認識的 | 這個人的**社交檔案**(IG、微信等),以及「在哪裡認識的」。很多人沒有自己的照片,IG 名稱也和真名不同 |
| 3 | 小李(業務) | 客人多,有意向、沒意向都要記 | 像秘書一樣記喜好和小事,**迅速想起**這個人;同一個人**多次見面**要分次記錄,日後可查 |
| 4 | 主人(婚禮、大型聚會) | 賓客互不認識,大咖不想別名牌 | **公開版**:看一眼就知道誰是誰。只能放自我介紹、特色、穿搭、喜歡的照片、社交帳號;**不能有胖瘦等私人評價** |
| 5 | 作者本人 | 平台很多(微信、小紅書、抖音、IG),常忘記哪次有誰 | 記**當下有誰來**,以及人和人之間的**關係**,免得下次邀約跳過中間人 |

## 從五個情境抽出來的共通結構

1. **人**:一個人只有一筆,長期存在。
2. **見面**:一個人可以有很多次見面;每次有時間、場合、當下的筆記。(情境 3、5)
3. **場合 / 聚會**:一次見面發生在哪個局,同一個局的人可以一起看。(情境 4、5)
4. **社交帳號**:一個人可以有多個平台的帳號,帳號名稱和暱稱分開記。(情境 2)
5. **關係**:人與人之間的連結,例如「小王介紹的」。(情境 5)
6. **私人和公開分開**:私人筆記永遠不離開手機;公開的只有本人自己填的自我介紹。(情境 4,也是原本的底線)
7. **好感度 / 重要度**:目前是 0.5–5 星。情境 1 想要的是「好感」,情境 3 想要的是「有沒有意向」,和情境 5 的「重要度」意思不同。(待決定)
8. **篩選**:依好感度、場合、平台、最近見面等條件找人。(情境 1、3)

## 和現在的程式比

| 項目 | 現況 |
|---|---|
| 人 + 私人筆記 + 重要度 + 記憶鉤子 | 有 |
| 見面(多次) | **沒有**,一個人只有一份筆記 |
| 社交帳號 | 只有自我介紹的欄位,私人筆記裡沒有 |
| 關係 | 沒有(列在後續功能) |
| 篩選 | 沒有 |
| 公開版穿搭 / 特色 | 自我介紹有,但沒有穿搭 |

## 已決定(2026-10-20)

1. **一個人一筆**。下面的備註可以一直加,每則自動帶時間戳記,用來記每次見面或約會。不另做「見面」紀錄表。
2. **重要度 = 好感度**,同一個數值。生活版維持 0.5–5 星,不露骨;約會版細分成 -5 到 +99。
3. **先做生活版**(情境 2、3、5)。約會版(情境 1)之後做。
4. **拆成兩個主要功能**:生活版、約會版。版面複製一份,各自調整。約會版會多出父母職業、收入、房、車等欄位。
5. **篩選先空著**。**穿搭欄位先空著**,之後做成上傳照片即可(公開版,情境 4)。

## 還沒決定

- 約會版的欄位清單(父母職業、收入、房車之外還有什麼)。
- 其他版本要不要做(見對話中的候選)。
- 生活版和約會版是 App 內切換,還是開啟時選一次。
