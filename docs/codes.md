# 標記碼對照表

畫面上每一個**可以互動的東西**(按鈕、選項、開關、輸入框、滑桿、可拖的星星與圓盤、可點的列)角落都有一個 3 碼小標籤。
下指令時直接說代碼,例如「P28 身高滑桿再長一點」「B07 拖的時候不要進入詳細頁」。

- 開關:每個畫面**右上角**都有一個浮動小圓鈕,點一下就顯示或隱藏所有標記碼(紫色「碼」= 顯示中,半透明「○」= 已隱藏);「我」分頁的 D36 是同一個設定。預設開啟,設定會記住。這個圓鈕本身沒有編碼。
- 同一個代碼在列表裡會重複(例如每一列人物的 B06、B07 都一樣),代表「那一類東西」。
- **新增或移動畫面元件時,請一併加上標籤並更新這份表。** 標籤用法見 `app/src/components/Tag.tsx`。
- 快速記錄的 P 碼在 2026-10-19 重做版面時整組重編(P01–P04 不變),舊的 P 碼作廢。

字母對應畫面:T 底部分頁、A 快速記錄、B 認識的人、C 聚會、D 我、E 人物詳細頁、F 掃描、G 聚會詳細頁、H 解鎖畫面、S 設定、P 記錄編輯器(A 和 E 共用)。
