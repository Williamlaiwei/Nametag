# 人物圖片需求規格(給圖片生成模型 / 插畫師)

這份文件有兩個用途:
1. 貼給別的圖片生成模型或插畫師,請他們照規格產出素材包。
2. 素材包打包後交回來,由程式照 `manifest.json` 讀取、疊圖。

## 1. 總體概念

Partyking 的人物是一個「全身小人」,用來讓使用者在派對上快速記住「這個人長什麼樣」。
人物由**零件疊圖**組成(身體、頭、頭髮、衣服、眼鏡),不是一張完整的人像。
同一組控制項(性別、體型、身材、身高、髮型、服裝、膚色、衣色、年紀、眼鏡)要能套到三種畫風。

**三種畫風**(各自一整套零件):

| 代號 | 名稱 | 風格重點 |
|---|---|---|
| kr | 韓國漫畫風 | 韓漫(webtoon)風。細長比例、細緻五官、柔和色彩、乾淨線條 |
| jp | 日本清透畫風 | 日系動漫、清透明亮的上色、大眼、柔和的高光 |
| us | 美式 Emoji 風格 | 美式卡通 / Emoji 風。圓潤、粗輪廓、鮮明色塊、表情誇張可愛 |

(參考圖由使用者另行提供。同一風格內所有零件必須是同一個畫風、同一套線條粗細和上色方式。)

## 2. 控制項與需要的變化

| 控制項 | 取值 | 需要素材嗎 |
|---|---|---|
| 風格 | kr / jp / us | 每種風格一整套 |
| 年紀階段 | 0 = 10歲以下、1 = 10–15、2 = 15–20、3 = 20–30、4 = 30–35、5 = 35以上 | 是,每階段外觀不同(臉型、頭身比、體態、皺紋等) |
| 性別 | 男 / 女兩種基底(App 上是 8 段滑桿,程式在兩者之間切換) | 是 |
| 體型 | 5 段:瘦、偏瘦、普通、偏壯、壯(胖瘦) | 是,身體輪廓不同 |
| 身材 | 4 段:一般、稍明顯、明顯、很明顯。女生 = 曲線(胸、腰、臀),男生 = 肌肉(胸肌、手臂) | 是,疊在身體上的加強層 |
| 身高 | 連續值 | **不需要**,程式把整個人縮放 / 拉長腿 |
| 髮型 | 5 種:光頭、寸頭、短髮、油頭、長髮 | 是,分前後兩層 |
| 髮色 | 10 色 | **不需要**,用單色遮罩由程式上色 |
| 膚色 | 11 色 | **不需要**,用膚色遮罩由程式上色 |
| 服裝 | 男 6:汗衫、短短(短袖短褲)、短長(短袖長褲)、長長(長袖長褲)、Casual、正裝。女 6:小可愛、短褲、長長、Casual、正裝、禮服 | 是 |
| 上衣色 / 下身色 | 15 色(黑、灰、白 + 12 色相)× 亮暗 | **不需要**,用上衣 / 下身遮罩由程式上色 |
| 眼鏡 | 有 / 無 | 是,一層 |

## 3. 圖層規格

### 3.1 畫布

- 所有零件**同一尺寸**:寬 1000 × 高 1400 像素(比例 5:7,與程式的 100×140 對應),透明背景。
- 最終使用的大小很小(最大約螢幕寬度),所以要**簡潔、輪廓清楚、細節不要太碎**。
- 人物正面站立、雙臂自然垂在身體兩側微微離開軀幹、雙腳分開與肩同寬。
- **站立基準線**:雙腳底部固定在 y = 1330,頭頂(不含頭髮)固定在 y = 150,**所有年紀、體型的零件都以這兩條線為基準**。年紀小的角色是縮短身體,不是縮小整張圖。
- **左右對稱**的零件(例如腿、手臂)只要出一邊也可以,程式會鏡射。
- 檔案格式:優先 **SVG**(分層);若只能產出點陣圖,用 **PNG(透明背景,32-bit)**。
- 不要有文字、浮水印、陰影地面或背景。

### 3.2 圖層順序(由下到上)

1. `hair_back` 後髮(長髮披在背後的部分)
2. `body` 身體:頸、軀幹、手臂、腿、手腳(穿內搭的素體,膚色區域單色,供上色)
3. `figure` 身材加強層(胸線 / 曲線 / 肌肉線條),透明疊在 body 上
4. `bottom` 下身(褲 / 裙 / 禮服下半)
5. `top` 上衣(含袖子;禮服是整件)
6. `shoes` 鞋(可含在 bottom)
7. `head` 頭與臉(五官、耳、頸接合處)
8. `glasses` 眼鏡
9. `hair_front` 前髮

### 3.3 上色用遮罩

為了讓程式可以換顏色,每個需要換色的零件要**同時提供兩份**:
- `*_line`:線稿 / 陰影層(不隨顏色變,通常是深色線條與陰影)
- `*_fill`:**純色平塗**的底色層(單一灰階,程式用乘色 / 填色方式染成目標顏色)

需要遮罩的零件:膚色(body、head)、髮色(hair_back、hair_front)、上衣色(top)、下身色(bottom)。
其他(鞋、眼鏡、五官)是固定色,不用遮罩。

## 4. 需要產出的數量

先做**第一批**驗證流程,通過後再擴充。

### 第一批(每種風格,只做 20–30 歲)

| 零件 | 數量 | 說明 |
|---|---|---|
| body | 2 性別 × 5 體型 = 10 | |
| figure | 2 性別 × 3(稍明顯、明顯、很明顯)= 6 | 「一般」不用加強層 |
| head | 2 性別 = 2 | 基底表情(微笑) |
| hair_front + hair_back | 5 髮型 × 2 性別 | 光頭不用髮。其餘 4 款各 2 層(長髮 / 女性短髮會有 back) |
| top | 男 6 + 女 6 = 12 | 含袖長變化;禮服為整件 |
| bottom | 男 6 + 女 5(禮服已含)≈ 11 | 長度依服裝 |
| glasses | 1 | |

(每個可上色零件另外附 `_fill` 遮罩。)

### 第二批(擴充年紀)

在第一批通過後,把 body、head、figure、服裝依 6 個年紀階段各出一套;髮型可以共用,但年紀小時(10 歲以下)頭身比不同,要重畫。

## 5. 命名規則與 manifest

檔名:`{style}/{age}/{gender}/{part}_{variant}.{ext}`,全小寫、英文、底線分隔。

- style:`kr` `jp` `us`
- age:`0`–`5`(對應年紀階段)
- gender:`m` `f`
- part 與 variant 範例:
  - `body_b0` … `body_b4`(體型 0–4)
  - `figure_f1` … `figure_f3`
  - `head_base`
  - `hair_front_h1` … `hair_front_h4`、`hair_back_h2`…(h0 光頭沒有檔;h1 寸頭、h2 短髮、h3 油頭、h4 長髮)
  - `top_o0` … `top_o5`、`bottom_o0` … `bottom_o5`(服裝索引,與 App 的順序一致,見下)
  - `glasses`
  - 遮罩檔多加 `_fill`,線稿檔多加 `_line`,例如 `body_b2_fill.png`、`body_b2_line.png`

服裝索引(與程式一致):
- 男:0 汗衫、1 短短、2 短長、3 長長、4 Casual、5 正裝
- 女:0 小可愛、1 短褲、2 長長、3 Casual、4 正裝、5 禮服

另附一份 `manifest.json`,列出每個檔案和它的錨點資訊:

```json
{
  "canvas": { "width": 1000, "height": 1400 },
  "baseline": { "footY": 1330, "headTopY": 150 },
  "styles": {
    "kr": {
      "3": {
        "m": {
          "body": { "b0": { "line": "kr/3/m/body_b0_line.png", "fill": "kr/3/m/body_b0_fill.png" } },
          "head": { "base": { "line": "...", "fill": "..." } },
          "hair_front": { "h1": { "line": "...", "fill": "..." } }
        },
        "f": {}
      }
    }
  }
}
```

## 6. 給圖片生成模型的重點提醒

- **一致性最重要**:同一風格的所有零件要像同一位畫師畫的。建議先產出一張「基準角色」(中性、20–30 歲、普通體型、站姿),之後所有零件都依這張的比例和線條。
- 一次只產出**一個零件或一個零件的幾個變化**,不要整個人一起生成再切割。
- 生成後請檢查:零件疊起來位置是否對齊(腳底在 y=1330、頭頂在 y=150)、有無多餘背景、線條粗細是否一致。
- 不要使用真人肖像或任何現有角色 / 品牌的形象。
- 請確認產出的素材**可以商用,且授權清楚**(附上來源、模型名稱、授權說明)。

## 7. 交付清單

- `manifest.json`
- 所有圖片檔(依命名規則)
- `README.txt`:使用的模型 / 工具、授權、已知問題
- 預覽圖:每種風格一張,顯示 3 個不同體型的組合

- 沒有對應素材的組合,退回目前手畫的預設小人。
